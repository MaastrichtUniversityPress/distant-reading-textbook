# The role of coding in Machines of Knowledge

In this course, the primary focus is on analyzing data using **Voyant Tools**, a data analysis suite with a graphical user interface (GUI). Working with code is entirely voluntary, so this page serves as additional information for those interested.

## Running code directly in your browser

For students who wish to explore coding, Monika Barget has prepared several **Python** scripts for tasks like data scraping, data cleaning and data visualisation. You will find these scripts throughout this interactive handbook, complete with explanations of each step. Python is a popular programming language for data analysis (in the humanities). To run the Python code, we will use a live coding environment directly in your browser, powered by *Sphinx* within *TeachBooks*, which is based on *JupyterBooks*. This setup allows you to interact with code cells embedded in the handbook without installing anything on your own machine. To start the live coding on page that contains code, you first have to press that **rocket button** at the top of that page.

Running code in the browser will be explained in an extra session. We will find a date for this session together, and all interested students can attend.

## JupyterHub

In the past, we used **JupyterHub** on Maastricht University's DSRI (Data Science Research Infrastructure) for this course. JupyterHub is a multi-user platform that provides a pre-configured **Jupyter Notebook** environment, in which you can also run code like Python scripts. The reason why we are not working with JupyterHub in the course now is that it costs quite some time to set up and maintain. However, it is our preferred set-up for research projects, and also for student theses. In JupyterHub, we can ensure that every user has the same interface and tools, and that those are running reliably. It also offers stable file storage, which is useful for long-term projects. If several students are interested in using code for their MA theses, such as collecting their own social media data, I may set up a JupyterHub instance again.

To access any JupyterHub hosted on the UM DSRI, you also need to run the UM VPN Client. At Maastricht University, we use the **Cisco AnyConnect VPN client**. Follow the [UM ICT VPN instructions](https://dsri.maastrichtuniversity.nl/docs/guide-vpn/) to set it up.

For VPN support, contact **UM ICT** directly:
- **ICT FASoS**: Visit in person by turning left at the reception and walking down the hallway with the red seats. Their office is usually open from 9 am to 4 pm on working days.
- **ICT Central**: Submit a request via the [online ticketing system](https://servicedesk.icts.maastrichtuniversity.nl/tas/public/ssp/) or visit their in-person service desk at the university library in the inner city.

To successfully connect to the VPN client, ensure you select access category **06** (for students) instead of **01** (for staff).
