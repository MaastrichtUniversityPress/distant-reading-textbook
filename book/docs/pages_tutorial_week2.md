## Task 2.3: Data visualization 1.0 – what charts are used for what type of data?

Data visualization is a powerful tool for communicating complex information in an accessible and engaging way. However, not all types of charts are equally suitable for all data sets, and data visualisations are never entirely neutral. The way in which you choose colours, add captions or labels, and highlight certain data points suggests a particular interpretation, so being aware of limitations and potential biases is important.

To make decisions about the right chart type for your data, you can use data visualisation **decision trees** such as [From Data to Viz](https://www.data-to-viz.com). A simpler and widely-shared overview of visualisation types and their purpose is offered in Andrew Abela's 2006 flowchart "Chart Suggestions: A Thought-Starter". Unfortunately, the original blog post is no longer online, but you can still find the overview here: [https://flowingdata.com/2009/01/15/flow-chart-shows-you-what-chart-to-use/](https://flowingdata.com/2009/01/15/flow-chart-shows-you-what-chart-to-use/)

Depending on how much time is left in the tutorial session, you can now get together in small groups of 3 or 4 students and begin to experiment with data visualisations in Excel, Google Sheets, or LibreOffice -- whatever software you commonly use to edit tables! Each group will be given one of the sample data sets below and asked to make several suitable charts representing these data visually. 

In Excel, options for making charts are in the Insert tab (Charts group). In Google Sheets, they are found via the Insert menu and then Chart, which opens the Chart editor on the right-hand side. In LibreOffice Calc, charts are created through the Insert menu and then Chart (or via the Chart icon in the Standard toolbar), which launches a chart wizard. Tools like Excel give you autosuggestions, but these may not be the best to use and often require careful customisation.

Until the next tutorial meeting, every group should be able to post (screenshots of) **three different charts** they made on the *Data Visualisation* discussion board and write a few sentences explaining the pros and cons of the selected charts. We will briefly discuss the results in the next tutorial session.
