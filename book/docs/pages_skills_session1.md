# Text Analysis I: Corpus Building and Tools for Distant Reading
### Tutor: Joris van Zundert

The first skills session in the *Machines of Knowledge* course is dedicated to corpus building and tools for distant reading. The tool that we will use for the practical exercises in this course is Voyant Tools, a suite of several text analysis tools.
