## Data Science at Maastricht

Maastricht University provides the so-called [Data Science Research Infrastructure (DSRI)](https://dsri.maastrichtuniversity.nl), a distributed and scalable infrastructure
for running data science projects. The DSRI allows you to deploy workspaces such as RStudio, JupyterLab, and Visual Studio Code directly from its web interface. Computing environments
can also be shared with other researchers at the university, and students can also be given limited access. The DSRI currently hosts 110 projects across 7 affiliations at Maastricht University.

### Using the DSRI for computational text analysis / NLP

The DSRI can be used for computational text analysis and NLP. In 2024/2025 and 2025/2026, the course *Machines of Knowledge* at Maastricht University used a JupyterHub hosted on the DSRI
to permit students to run Python code for data collection and data cleaning.
However, changing access requirements and a redesign of the cluster in 2025 made constant updates to the course materials necessary, which did not seem sustainable in the long run.
Students in Machines of Knowledge are therefore no longer introduced to working with the DSRI at present. However, students who would like to use computational methods in their MA thesis may still need access.
Please discuss your plans for the thesis with the programme director early so that the necessary arrangements can be made.
